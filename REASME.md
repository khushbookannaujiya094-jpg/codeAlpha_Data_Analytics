# CodeAlpha Data Analytics Internship

## Project: Titanic Data Analysis

### Tasks Completed
- Task 2: Exploratory Data Analysis (EDA)
- Task 3: Data Visualization

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Titanic passenger dataset.

## Analysis Performed
- Dataset exploration
- Missing value analysis
- Data cleaning
- Survival analysis
- Gender-wise survival analysis
- Passenger-class analysis
- Age and fare analysis
- Data visualization

## Key Insights
- Female passengers had a higher survival rate than male passengers.
- First-class passengers generally had a higher survival rate.
- The dataset contains passengers from different age groups and classes.
